# ☕ Coffee Bar - Cafetería de Especialidad

Sitio web responsivo e interactivo diseñado para una cafetería de especialidad. El proyecto presenta una interfaz moderna y atractiva utilizando prácticas actuales de desarrollo web como **Flexbox** para el maquetado estructural y un diseño totalmente adaptable a dispositivos móviles.

---

## 🚀 Características Principales

*   **Diseño Responsivo:** Adaptado para celulares, tablets y computadoras de escritorio mediante *Media Queries*.
*   **Maquetado con Flexbox:** Estructura limpia y flexible en todas las secciones clave (Menú, Productos, Blog y Pie de página).
*   **Menú Hamburguesa Nativo:** Navegación móvil funcional implementada de forma nativa con HTML y CSS (sin necesidad de JavaScript).
*   **Estilo Visual Atractivo:** Uso de tipografías modernas (*Roboto*), efectos de transición suaves y capas de degradado sobre imágenes para garantizar una alta legibilidad del texto.

---

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructuración semántica del contenido del sitio.
*   **CSS3:** Estilado avanzado, tipografías externas y diseño flexible.
*   **Google Fonts:** Integración de la fuente tipográfica *Roboto*.

---

## 📁 Estructura del Proyecto

Para que el sitio web cargue todos sus recursos e imágenes de manera correcta, asegurate de mantener la siguiente estructura de carpetas:

```text
├── index.html          # Archivo HTML principal
├── style.css           # Hoja de estilos CSS
└── imagenes/           # Carpeta de recursos visuales
    ├── bg-cafeteria.jpg # Imagen de fondo del encabezado
    ├── bg2.png         # Imagen de fondo secundaria
    ├── menu.png        # Ícono para el menú móvil
    ├── c1.png, c2.png  # Imágenes de la sección de productos
    ├── blog1.jpg, etc. # Imágenes de la sección del blog
    └── i1.svg, i2.svg  # Íconos vectoriales de servicios
```

---

## ⚙️ Instalación y Uso Local

1.  **Cloná o descargá** este repositorio en tu computadora.
2.  Asegurate de que las imágenes requeridas estén ubicadas dentro de la carpeta `imagenes/` con los nombres correspondientes.
3.  Abrí el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).

---

## 📝 Secciones del Sitio

1.  **Header / Inicio:** Pantalla de bienvenida con una imagen de fondo de alto impacto sobre madera, título del negocio y acceso directo al menú.
2.  **Nuestra Selección:** Catálogo de cafés destacados (Espresso, Filtrado, Flat White) presentados en tarjetas flexibles independientes.
3.  **Servicios:** Bloque con fondo fijo (*parallax effect*) que destaca las prestaciones adicionales de la cafetería.
4.  **Información / Destacados:** Dos secciones alternadas con imágenes y textos descriptivos sobre el tueste artesanal y el ambiente del local.
5.  **Blog Cafetero:** Artículos de interés sobre métodos de extracción, conservación y arte latte.
6.  **Footer:** Pie de página organizado en cuatro columnas con enlaces de navegac
